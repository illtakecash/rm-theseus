# Validation

Precommitted before any run. Changing a criterion after seeing outputs requires a new dated entry here, the old text kept, and Scott's approval.

| ID | Criterion | Pass | Fail means |
|---|---|---|---|
| V-DRIFT | On `theseus-history`, each assessor names the divergence (matching or defensibly extending the sealed key), a causal chain citing decision IDs, one excluded alternative, and a recovery or revision. | All four elements, independent and contextual, judged against the key by Scott or a grader that hasn't seen the outputs' authors. | C-TRAJ/C-CAUSE/C-ALT/C-CORR not demonstrated. |
| V-CTRL | On `control`, neither assessor reports drift. | No drift finding. | False alarm; detector is just pattern-matching "governance = bad". |
| V-BASE | Compare B3 to the B1 plain-prompt baseline (a real competitor, run under the same packet budget rules and graded blind against the same keys) on every V-DRIFT element across both assessors, plus V-CTRL. Results go in a per-case, per-dimension table marked better / tie / worse. | Either (a) B3 is better on at least two dimensions spanning at least two of {`theseus-history` independent, `theseus-history` contextual, `control`}, and worse on none; or (b) equal detection quality on every dimension with a cost vector (V-COST) that is lower on at least one component and higher on none. | Anything else fails the gate, including acknowledged regressions and all-ties. The run is still a valid, reported experiment; ties and regressions are listed by name, never summarized as success. B5 does not start until Scott decides whether to rethink, revise, or stop. |
| V-HELD | `consulting-os`, key sealed before B4; no model output (baseline or method) is produced on it until the method is frozen at B5; no tuning after unseal. Baseline and method both run on it at B5. | V-DRIFT elements hold; the finding states that governing the inherited Python implementation is not making implementations replaceable. | Overfit to Theseus. |
| V-TRAJ | Sensitivity: reorder, drop, or insert one decision in `theseus-history`. | Divergence point moves or holds in a way the cause explains. Shuffling all decisions should degrade the finding. | Assessor isn't reading the trajectory. |
| V-ISO | Isolation evidence for the independent pass: process, filesystem, network, model memory, model family. Each marked restricted, disclosed-unrestricted, or unknown. | Report is complete and truthful; anything not restricted is labeled. `independence_unverified` blocks any authorization that cites that assessment. | C-DUAL overstated. |
| V-CORR | Correction loop with one failed correction. | Failed correction leaves the finding open; successful one clears it on re-run. | C-CORR not demonstrated. |
| V-BOUNDARY | Independent-packet lint, run on every independent pass (B3 onward). | Packet contains a `fact` for every decision in the case, in order, with date and actor; contains no `rationale`, `diagnosis`, `assessment`, or `conclusion` field, and no free text from those fields of any other record. Lint result is sealed with the output. The lint is necessary, not sufficient: B3 also runs an interpretive-leakage check on `fact` values (evaluative or causal language, e.g. "mistakenly", "to fix", "because"), flagged for Scott's review before grading. | Either independence was leaked (rationale in) or trajectory was starved (facts missing); the pass is invalid for C-DUAL. |
| V-RETAIN | Intent-retention probe: from a loop packet alone (plus pulls), an agent states the governing objective and the principles relevant to the step. | Matches `intent.md` on objective and every principle in the packet's graph slice. | Compression lost intent; enlarge packet or fix graph. |
| V-COST | Cost per loop as a vector, never summed across unlike units: `input_tokens` (packet), `retrieval_tokens` (pulls), `output_tokens`, `reconstruction_calls` (extra model calls spent re-deriving context). Recorded from B1 onward; benchmarked at B7 against a full-document loop on the same tasks. A composite is allowed only with weights written here, dated, before the run. | V-RETAIN passes first (a retention failure voids any cost win). Then the packet loop is lower on at least one component and higher on none, or lower on the pre-declared weighted composite with each component reported. | Compression is a token trick, not a saving. |

**Honest limitations, stated now.** Local isolation can't verify a hosted model's server-side memory. Same-family models (Grok Bot and its own cloud agents) have correlated errors; a cross-family independent run is stronger. Scott writing the keys means grading against his reading of drift, which is the intended authority but not ground truth.
